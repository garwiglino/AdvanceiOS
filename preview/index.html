01 / LIBERTÉ

La croix vient à toi.

Tout contact dans la moitié gauche crée un nouveau centre. Glisse pour choisir l’une des huit directions ; relâche pour le libérer.

02 / CONFORT

Les actions à portée de pouce.

A/B en diagonale, L/R juste au-dessus. Start, Select et Pause restent en haut. Les zones respectent les marges de sécurité.

03 / CLARTÉ

Juste le contour.

Fond transparent, trait blanc et opacité réglable. Un éclaircissement confirme l’appui ; aucun bouton en relief ne masque le jeu.

Flèches · X / Z = A / B · Q / E = L / R · Entrée = Start · Maj = Select · Échap = Pause
Sur écran large, des bandes préservent l’image entière. Les marges des formats sont simulées ; l’application utilise celles d’iOS.
